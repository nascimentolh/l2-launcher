# Lineage II Launcher — ReverieGames

Ponto de download do launcher dos servidores **L2 Darion** e **L2 Reverie**.

👉 **[Baixar a última versão](../../releases/latest)**

Um launcher só para os dois servidores: instala o cliente do zero, atualiza o que mudou
(arquivo por arquivo, conferido por sha256 contra um manifesto assinado), guarda suas contas
e abre o jogo.

- **Windows 10/11.** Precisa do *Microsoft Edge WebView2 Runtime* (já vem no Windows atualizado).
- Arquivo único: não tem instalador nem pasta extra. Baixou, abriu, pronto.
- Depois de instalado ele se mantém atualizado sozinho.

Sites: [l2darion.com](https://l2darion.com) · [l2reverie.com](https://l2reverie.com)

> Este repositório guarda **apenas o download**. O código-fonte não é público.
